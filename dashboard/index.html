Multi-Agent Communication Protocol Study

Communication format is an experimental variable, not just an implementation detail.

The walkthrough moves from experiment idea to protocol basics, then runs one live protocol comparison, opens the saved experiment database, and finishes with aggregate results and recommendations.

Research Question

How do NL, Markdown, JSON, and Shared Memory affect multi-agent cost, latency, and completion quality?

The project holds the model, agent roles, task domains, and prompts constant, then varies only the inter-agent communication protocol.
